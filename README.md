# Growth Audit · Serasa

Protótipo clicável e cinco ideias para o paywall do Serasa Premium, refeitos no próprio design do app.

**Ver ao vivo:** https://hribeiro-adapty.github.io/serasa-flow-rebuild/

| # | Ideia | Faixa esperada |
|---|---|---|
| 1 | Dê uma segunda chance ao voltar, com o plano mensal | ARPU +10–15% |
| 2 | Diga o que a pessoa recupera no título | Conversão +15–20% |
| 3 | Coloque a nota da App Store acima do botão | Conversão +10–15% |
| 4 | Mostre quanto o plano anual economiza | ARPU +10–15% |
| 5 | Inclua os benefícios que o paywall omite | Conversão +5–10% |

Preços, nota e avaliações vêm da tela do app, da App Store e do serasa.com.br/premium. As faixas são o efeito esperado pela Adapty a partir de análises e testes A/B em apps de assinatura, não ganho medido para a Serasa.

Para rodar localmente: `python3 -m http.server 8000` nesta pasta.
